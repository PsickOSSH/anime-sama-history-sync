Politique de confidentialité

Anime Sama - History Sync | Version 1.1.5 | Mise à jour : 1er novembre 2026

1. Données collectées

  • Identité Google : Nom, email, photo de profil (via OAuth 2.0)
  • Historique anime-sama : Données depuis localStorage anime-sama (visionnage, favoris, watchlist)
  • Tokens d'authentification : Refresh token et access token pour accéder à Google Drive
  • Onglets du navigateur : L'extension liste uniquement les onglets Anime-Sama ouverts (autorisation limitée aux domaines Anime-Sama) pour mettre à jour l'état de connexion en temps réel sur vos pages, et ouvre le site via l'icône. Elle n'accède jamais aux URL, titres ou contenus des autres sites web.
  • Affichage : Le panneau de synchronisation charge le logo d'Anime-Sama depuis cdn.statically.io (service tiers). Votre adresse IP est donc visible de ce service lorsque vous ouvrez la page profil.

Important : L'extension n'accède jamais aux données du serveur anime-sama. Elle synchronise seulement les données stockées localement dans votre navigateur.

2. Où vos données sont stockées

Stockage Contenu Chiffrage
Google Drive (appDataFolder) Historique anime-sama (fichier anime-sama-history.json) AES-256 (chiffrement Google)
Navigateur local Refresh token, access token, métadonnées utilisateur, dernier état synchronisé de l'historique (pour fusionner les modifications entre appareils) Stockage local non chiffré
Backend OAuth (Cloudflare Workers) Logs techniques : IP, horodatage, code d'autorisation, refresh token (transit uniquement) Conservés 7-30 jours
Risque de sécurité critique : Le refresh token est stocké en plaintext dans chrome.storage.local ou browser.storage.local. Un attaquant avec accès local (malware, utilisateur partagé avec permissions admin) peut le voler et accéder, tant que vous ne vous êtes pas déconnecté ou que vous n'avez pas révoqué l'accès, au fichier de sauvegarde de l'extension (appDataFolder) ainsi qu'à votre nom, photo et adresse email. Il n'a pas accès à vos autres fichiers Google Drive. Ne partagez pas votre ordinateur avec d'autres utilisateurs.

3. Backend OAuth (Cloudflare Workers)

L'extension communique avec un backend sécurisé hébergé sur Cloudflare (oauth-backend.psickossh.workers.dev) pour :

  • Échanger le code d'autorisation OAuth contre des tokens (évite d'exposer le client_secret dans l'extension)
  • Renouveler l'access_token lorsqu'il approche de son expiration (vérification toutes les 15 minutes environ, et au premier refus de Google Drive)

Le backend traite uniquement : code d'autorisation, refresh token (en transit), et métadonnées techniques (IP, horodatage). Aucune donnée d'historique anime-sama ne transite par ce backend.

4. Synchronisation multi-appareils

Votre historique est accessible sur tous les appareils où vous connectez le même compte Google. Tout nouvel appareil utilisant votre compte Google peut charger votre historique anime-sama complet. Ne partagez pas votre compte Google si vous souhaitez garder vos données privées.

Détection automatique des changements : L'extension surveille en temps réel les modifications dans votre historique anime-sama (vérification toutes les 2 secondes). La sauvegarde vers Google Drive se déclenche automatiquement environ 1 seconde après un changement. Si votre historique a été modifié à la fois sur cet appareil et ailleurs, les deux versions sont fusionnées (en cas de conflit sur une même entrée, la version de l'appareil en cours d'utilisation est conservée). Une copie de l'historique local est conservée dans le navigateur avant toute mise à jour (anime-sama-pre-sync-backup).

5. Qui accède à vos données

  • Vous : Via votre compte Google ou directement sur Google Drive
  • Éditeur de l'extension (PsickOSSH) : L'historique n'est jamais envoyé au backend. En revanche, le code d'autorisation et le refresh token transitent par le backend OAuth que j'héberge, et les journaux techniques de celui-ci (IP, horodatage) sont accessibles par moi. Ils ne servent qu'au fonctionnement et au dépannage.
  • Cloudflare (hébergeur du backend OAuth) : Voit les métadonnées de renouvellement de tokens et IP (USA, encadré par clauses contractuelles types RGPD)
  • Google : Stocke vos données dans Google Drive, chiffrées avec AES-256

6. Vos droits (RGPD) & Portabilité

  • Accès : L'accès au fichier anime-sama-history.json nécessite un outil compatible avec l'API Google Drive (l'interface Drive Web classique ne l'affiche pas car il est dans le dossier caché appDataFolder).
  • Exportation / Importation : Vous pouvez désormais télécharger une copie locale de votre historique (format .json) ou importer un fichier de sauvegarde directement depuis l'interface ajoutée au site Anime-Sama, garantissant la portabilité de vos données.
  • Suppression : La suppression du fichier n'est pas possible via l'extension. Vous pouvez supprimer le fichier manuellement depuis Google Drive en allant dans Paramètres → Gérer les applications → Anime Sama - History Sync → Supprimer les données associées.
  • Retrait du consentement : La déconnexion de l'extension révoque les tokens auprès de Google, supprime les tokens et les données de session du navigateur et empêche toute nouvelle collecte de données, mais ne supprime pas les données déjà stockées dans Drive. Pour les effacer, utilisez la procédure de suppression via Google Drive décrite ci-dessus.

7. Pas de tracking, pas de pub

  • Aucun cookie posé par l'extension (la fenêtre de connexion Google peut en utiliser, selon les règles de Google)
  • Aucun pixel de suivi
  • Aucun analytics
  • Vos données ne sont jamais vendues

8. Sécurité

  • OAuth 2.0 (secrets gérés par Cloudflare Workers, jamais exposés dans l'extension)
  • HTTPS/TLS 1.2+ pour toutes les communications
  • Refresh token valide indéfiniment jusqu'à votre déconnexion ou révocation via votre compte Google
  • Access token renouvelé automatiquement avant expiration
  • Les tokens de connexion mobile ne sont enregistrés qu'après confirmation du compte par l'utilisateur, et sont retirés de l'URL immédiatement
  • Révocation : Si compromis, révoquez manuellement l'accès via Google Account

9. Permissions de l'extension

L'extension déclare les permissions suivantes dans son manifest :

  • identity : Authentification Google OAuth 2.0
  • storage : Stockage local des tokens et métadonnées utilisateur
  • alarms : Planification du renouvellement du token d'accès

La permission tabs n'est pas utilisée : l'extension ne peut pas lire les URL ni les titres de vos onglets.

Permissions d'accès réseau :

  • https://anime-sama.tv, .si, .to, .org, .fr, .eu, .pw : Accès au localStorage du site pour récupérer l'historique
  • https://psickossh.github.io/anime-sama-history-sync/Anime-Sama-History-Sync-Profil.html : Page de profil de l'extension (connexion mobile)
  • https://www.googleapis.com/* : Communication avec l'API Google Drive
  • https://oauth-backend.psickossh.workers.dev/* : Backend OAuth sécurisé

10. Scopes Google Drive

L'extension demande uniquement les accès suivants à votre compte Google :

  • https://www.googleapis.com/auth/drive.appdata : Accès au dossier caché appDataFolder (invisible sur l'interface web Drive)
  • https://www.googleapis.com/auth/userinfo.profile : Nom et photo de profil
  • https://www.googleapis.com/auth/userinfo.email : Adresse email

L'extension ne demande aucun accès à l'ensemble de votre Drive et ne peut jamais accéder à vos autres fichiers Google Drive personnels.

11. Compatibilité mobile

Sur les appareils mobiles (Android, iOS), la connexion Google s'effectue via la page psickossh.github.io/anime-sama-history-sync. Après authentification, cette page renvoie les tokens à l'extension via l'adresse de la page (fragment # de l'URL). L'extension demande confirmation du compte avant de les enregistrer, puis les efface de l'URL.
